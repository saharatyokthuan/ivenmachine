# Vending Machine Management System

ระบบจัดการตู้จำหน่ายสินค้าอัตโนมัติ (Vending Machine Management System) — เว็บแอปสำหรับนำเข้าข้อมูลตู้
ตรวจสอบสถานะเครื่อง สรุปเหรียญ/สินค้าที่ต้องเติม และส่งออกรายการเติมสินค้าเป็นไฟล์ Excel/CSV/JSON

> 🌐 **ใช้งานออนไลน์:** https://saharatyokthuan.github.io/ivenmachine/

---

## ✨ ฟีเจอร์หลัก

- **📥 นำเข้าข้อมูลได้หลายรูปแบบ** — `.txt` (vending.txt), `.xlsx`, `.csv`, `.json`
- **📊 ภาพรวมข้อมูลเครื่อง (Machine Overview)** — รหัสเครื่อง (Activation Code), จังหวัด, อำเภอ, GM, พื้นที่
  และสถานะต่าง ๆ (เครื่อง, สต๊อก, สแกนเนอร์, อุณหภูมิ, ธนบัตร, ลิฟท์ส่งสินค้า, ประตู ฯลฯ)
- **🪙 สรุปเหรียญที่ต้องนำไปเติม** — เทียบกับความจุสูงสุด (1 บาท = 100, 5 บาท = 100, 10 บาท = 60 เหรียญ)
- **📦 สรุปสินค้าที่ต้องนำไปเติม** — เกณฑ์สูงสุด 4 ชิ้น/ช่อง, ค่าติดลบถือเป็น 0
- **🗄️ แผนผังตู้จำหน่ายสินค้า** — แสดงสถานะสินค้าแต่ละช่อง แยกตามชั้น (6 ชั้น × 9 ช่อง: 11–19, 21–29, …, 61–69)
- **📋 ข้อมูลสินค้าทั้งหมด (Master Product List)** — พร้อมหมวดหมู่ (PMA) และข้อมูลประกอบ
  มีช่องค้นหาและตัวกรองตามหมวดหมู่/สถานะ
- **📤 ส่งออกข้อมูล** — `.xlsx` (ไฟล์ `product.xlsx` มีชีต "การเติมสินค้า" เป็นชีตแรก), `.csv`, `.json`
- **💾 บันทึกข้อมูลอัตโนมัติ** — ข้อมูลที่นำเข้าจะถูกบันทึกไว้ในเบราว์เซอร์ (localStorage) ไม่หายเมื่อรีเฟรช

---

## 🚀 วิธีใช้งาน

1. เปิดเว็บแอป (ออนไลน์ หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์)
2. กดปุ่ม **Import** แล้วเลือกไฟล์ข้อมูลที่ต้องการ (`.txt` / `.xlsx` / `.csv` / `.json`)
3. ระบบจะประมวลผลและแสดงผลในส่วนต่าง ๆ ของหน้าเว็บโดยอัตโนมัติ
4. ตรวจสอบรายการที่ต้องเติม แล้วกด **Export** เพื่อดาวน์โหลดไฟล์นำไปใช้งาน
5. หากต้องการกลับไปใช้ข้อมูลเริ่มต้น กดปุ่ม **รีเซ็ต** (ในส่วน "ข้อมูล" บนแถบด้านบน)

## 📁 รูปแบบไฟล์ที่รองรับ

### Import

| รูปแบบ | รายละเอียด |
|---|---|
| `.txt` | ไฟล์ `vending.txt` — แทนที่ข้อมูลเครื่อง + เหรียญ + ช่องขาย (ช่องสินค้า) |
| `.xlsx` | ไฟล์ `product.xlsx` แบบหลายชีต รองรับชีต `Machine`, `Slots`, `Products`, `PMA` |
| `.csv` | ไฟล์ CSV ของ **Slots** (มีคอลัมน์ `slot`) หรือ **Products** (มีคอลัมน์ `Master Product ID`) |
| `.json` | ไฟล์สำรองข้อมูลรวม (`machineData`, `slotsData`, `productsData`, `pmaData`) — ได้จากปุ่ม Export JSON |

### Export

| รูปแบบ | ชื่อไฟล์ |
|---|---|
| `.xlsx` | `product.xlsx` (ชีตแรก "การเติมสินค้า" พร้อมสูตรคำนวณ) |
| `.csv` | `product_<วันที่>.csv` (มี BOM รองรับภาษาไทยใน Excel) |
| `.json` | `product_<วันที่>.json` (สำรองข้อมูลทั้งหมด) |

## 💾 การบันทึกข้อมูล

- ข้อมูลที่นำเข้าจะถูกบันทึกใน **localStorage** ของเบราว์เซอร์โดยอัตโนมัติ (คีย์ `vending_machine_state_v1`)
- เมื่อเปิดหน้าเว็บใหม่ ระบบจะ **กู้คืนข้อมูลล่าสุด** ที่บันทึกไว้ให้อัตโนมัติ
- กด **รีเซ็ต** เพื่อล้างข้อมูลที่นำเข้าและกลับไปใช้ข้อมูลเริ่มต้น (มีกล่องยืนยันก่อนทำรายการ)
- ข้อมูลถูกเก็บไว้ในเครื่องของผู้ใช้เท่านั้น ไม่มีการส่งไปยังเซิร์ฟเวอร์ใด ๆ
- หากต้องการล้างข้อมูลด้วยตนเอง: ล้าง Site data / Local Storage ของเบราว์เซอร์

## ℹ️ หมายเหตุ

- ค่าสูงสุดต่อช่อง (MAX) ตั้งต้นที่ **4 ชิ้น/ช่อง**
- สถานะสินค้าใน Master Product List: `publish` (เผยแพร่) และ `disable` (ปิดใช้งาน)
- การนำเข้าไฟล์ `.xlsx`/`.csv` จะอัปเดตเฉพาะชีต/ส่วนที่มีในไฟล์ ส่วนที่ไม่มีจะคงค่าเดิมไว้
- แนะนำให้ Export เป็น `.json` เก็บไว้เป็นข้อมูลสำรองก่อนรีเซ็ตหรือเปลี่ยนเครื่อง
